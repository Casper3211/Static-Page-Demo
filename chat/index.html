How to add or update your key
  1. Sign in at OpenRouter Keys and choose Create Key.
  2. Copy your key and paste it into the password field below.
  3. Click Use / update key, then send a theme such as “food”.
  4. To replace it, paste a new key and click the same button. Revoke the old key on OpenRouter if you no longer need it.

Paste into this live page, not the HTML code on GitHub. Published code is public. Each visitor uses their own key and quota. GitHub Secrets cannot be read privately by a static webpage.
